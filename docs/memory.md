# 记忆分层

| 层 | 位置 | 上限 | 用途 |
|---|---|---|---|
| 当天缓冲 | kv `episodic_memory` | 12 条 / 600 字 / 36h | 过夜追问 |
| 日记 digest | kv `day_digest:<日期>` + 日记正文 | 1 行/天，80 字 | 长期可查 |
| 聊天注入 | 动态上下文 | 最近 3 天，≤240 字 | 让她想起来 |
| 长期记忆 | 数据插件库 | 周清理/90 天归档 | 共同经历 |

- 缓冲按 key 合并，同一天同类事只留一条；
- 折叠成功才清缓冲，失败保留；
- 日记重写会重新带上 digest，不丢；
- 不往记忆库逐条写行，避免膨胀。
