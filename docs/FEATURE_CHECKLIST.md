## 0. 怎么用

#### P0 —— 阻断 / 回归（做不完不许往下走）

| 项 | 要求 | 证据（必填） | ✅ |
|---|---|---|---|
| 备份 | 开工前整目录快照，路径可 `ls` | `D:/dafeiyu/backup/<名字-时间戳>`（N 个文件） | ☐ |
| 回滚 | `plan` 能跑通；关键轮次给 `manifest.json` 并演练过一次 | `rollback.py plan … EXIT 0`、apply 演练退出码 | ☐ |
| 默认行为 | 默认行为零变化；若必须变，先说明并给 A/B | A/B 命令 + 逐字节/逐字段一致的结论 | ☐ |
| 全量 + gate | 全量 pytest 不红 + gate EXIT 0 | `N passed / M skipped`、`gate EXIT 0`（贴 5 行数字） | ☐ |
| 真实数据 | 不写 plugin_data；确需改（迁移/清理）必须先热备 | 库 sha256 前后、热备路径、审计键 | ☐ |

#### P1 —— 正确性 / 一致性（最容易走过场的一栏）

| 项 | 要求 | 证据（必填） | ✅ |
|---|---|---|---|
| 边界/异常 | 空值、空列表、超长、非法类型 | 测试名 `test_xxx.py::test_yyy` | ☐ |
| 旧数据 | 老库/老 JSON/旧 kv 前缀仍能读；升级幂等 | 用备份的旧库副本跑通的日志/测试 | ☐ |
| 版本/状态切换 | 迁移按序、只前进、失败不阻断启动 | `user_version` 断言、迁移测试 | ☐ |
| 失败回退 | 外部依赖（能记/守护/LLM/网络）不可用时的降级路径 | 测试名 + 降级后的返回值 | ☐ |
| **跨模块不变量** | 列出本次触碰的每条链路，**两端同时断言** | 见 §2 清单；缺哪条就写「不涉及 + 理由」 | ☐ |
| 新增测试 | 新逻辑有对应用例，且能被 gate 收集到 | `collect` 前后差值 | ☐ |
| **反向验证 ≥2** | 去掉规则必红、恢复必绿（脚本或日志留档） | 改坏后 `N failed`、恢复后 `N passed` | ☐ |

#### P2 —— 性能 / 冗余 / 可读性

| 项 | 要求 | 证据（必填） | ✅ |
|---|---|---|---|
| 重复调用 / 重复读库 | 一次请求内同一数据源不重复读；有前后对比 | `文件:行`、before/after 次数或耗时 | ☐ |
| 不做全量扫描 | 列表/巡检走增量或区间，不整表遍历 | 说明 + 数据量级 | ☐ |
| 函数长度 | 新函数 < 120 行，文件不逼近 1800 行 | `structure_audit.py` 输出 | ☐ |
| 异常可读 | 无裸 `except: pass`；必须吞的写 `_note_swallowed` 或 `# cleanup` | gate `check_silent_except` 通过 | ☐ |
| 可读性 | 命名/注释说明「为什么」，不留 TODO | `TODO/FIXME = 0` | ☐ |

## 2. 跨模块不变量清单（填 P1 时逐条对照）

改动碰到左侧 → 必须给出右侧的**双边**测试；没碰就写「不涉及」。

| 链路 | 必须同时断言什么 |
|---|---|
| 钱包 ↔ 日程消费 | 同一笔消费在账本与日程块里金额/时刻一致；幂等键不重复扣 |
| 约会 ↔ 聊天地点 | 会话地点变了，聊天守卫（place/reply_fact）按**新**地点判否；结束后各回各家 |
| 旅游 ↔ 账本 | 行程单总额 == ledger 支出；退款/重算后两侧同额；财务义务不走旅行溢价 |
| 面板 ↔ 库 | 面板显示条数/金额 == canonical 表（schedule 表，非 kv）；GET 只读不写 |
| 物价 ↔ 账本/历史 | 价目版本选择正确；city/item 命中顺序正确；历史账目不被新价目改写 |
| housing ↔ 照片 | 房间画像 → 场景/锁/参考图一致；housing 故障时降级且**留痕**（不静默） |
| 日程 ↔ 存储 | `save_day` 是唯一写口；表与 kv 同步（`test_schedule_invariants_storage.py`）；写入口绕闸必红 |

## 3. 判定线（收尾自查，全 ☑ 才算完成）

- [ ] P0/P1/P2 三栏**没有空格**，每格都有「可复跑的」证据。
- [ ] `pytest` 全量绿；`gate` EXIT 0（三插件各自）。
- [ ] 反向验证 ≥2 条**有留档**（退出码/日志），不是口头结论。
- [ ] 回滚点明确：备份路径 + `rollback.py plan` 通过；关键轮次有 `manifest.json`。
- [ ] 真实库未被本次改动污染（或已热备 + 记审计键）。
- [ ] 版本号/CHANGELOG/README/metadata 未动（除非用户明确说「更新版本号」）。
- [ ] 没有上传、没有热重载到线上（除用户明确要求）。

**任何一条不满足 → 不算完成，不得打包/上传。**

## 4. 常用命令（能陪为例，路径按插件替换）

```bash
PY=D:/dafeiyu/uv/tools/astrbot/Scripts/python.exe
cd D:/dafeiyu/astrbot/data/plugins/Astrbot_amoupup_forever

$PY -m pytest -q                      # 全量
$PY -m pytest --collect-only -q tests/ | tail -1   # 用例数
$PY tools/quality_gate.py             # 全量 gate
$PY tools/quality_gate.py --fast      # 跳过单测
$PY work/structure_audit.py           # main.py 行数 / >1800 / >120 / TODO

# 回滚（注意：--root 必须放宽，备份在 D:/dafeiyu/backup 下）
$PY tools/rollback.py plan --root D:/dafeiyu \
    --backup D:/dafeiyu/backup/<备份目录> --target D:/dafeiyu/astrbot/data/plugins/Astrbot_amoupup_forever
$PY tools/rollback.py manifest --dir <备份目录>        # 生成清单（写操作）
```
